# Changelog

## 0.1.0
- Core: pairing page, plugin loader with hot reload, idle switch, native interactive layer with text fallback, Unicode UI kit
- Channel forwarder: durable queue, retries, lookback, media download for keyless channel media, native channel tag (`ocfwd`), promo detection
- Group admin: kick, add, promote, demote, tagall, hidetag, mute, link, warn system, anti-link, welcome
- Mini apps: HTML games (Tic Tac Toe, Snake, 2048, Memory, Quiz) with on-screen controls, chat games (ttt, guess, trivia)
- Tools: pfp, qr, short, sticker, toimg, vv
- Download: YouTube (keyless API) and TikTok
- Info: weather, translate, wiki, define, currency
